# No-Skills protocol behavior tests

These four independent demonstration projects test Phase 0 protocol development through the local Python CLI. They are protocol behavior tests, not research results.

Each retains the exact requested question, uses one appropriate research type, and contains substantive scope, subquestions, definitions, proposed search approaches, eligibility criteria, applicable evidence extensions and unresolved human decisions. Draft inputs were saved with `update-protocol`; protected identity, approval and state fields were not edited.

All four passed `protocol-status` and `validate --require-substantive-protocol`: schema valid, substantively populated, draft, pending human review and unapproved. Phase 0 remains in progress; later phases remain pending. No approval or advance command ran.

No project or global Skill was inspected, invoked or used. No web or database search, source retrieval, screening, full-text reading or evidence verification occurred. No publications or findings were invented. Search venues and scope additions are proposals requiring human review.

`RUN_MANIFEST.json` is a privacy-filtered presentation of the historical CLI arguments, outputs, exit codes, control-file hashes, per-project status and failures. Host paths are repository-relative in this public copy. Private transcripts and original checksummed event journals are excluded, not rewritten; these saved draft snapshots are not recovery archives or approval records. Initial empty-protocol readiness diagnostics were expected; no CLI command failed in that historical run. Generated protocols have no `example_data` schema field; titles and narratives label their demonstration purpose. No evidence rows were created. Publication preparation does not constitute a rerun.
