# Demonstration Case Only

Everything in this directory is isolated example material transcribed or refactored from the source teaching case. It is **not verified evidence**, is **not a default**, and must not be copied into another research project unless the user explicitly chooses this example topic.

The paper IDs, evidence IDs, claims, gaps, and prose in the teaching case are hypothetical illustrations. They do not assert that any real paper exists or supports the stated result.

- `config.json` is an example Phase 0 configuration.
- `SOURCE_CASE_EXAMPLES.md` preserves the teaching case's topic-specific concepts, searches, variables, illustrative evidence, claims, gaps, and outline outside the core workflow.

Any generated demonstration row must use `example_data=true` and validation must be run with `--allow-example-data` only inside an explicit demo.
