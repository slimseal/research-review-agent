# Start a review — beginner-friendly prompt

Only the Research Question and necessary scope are needed. Database names and keys are optional.

```text
Research Question: [exact question]
Research field and purpose: [optional]
Necessary scope: [population/context/date/language constraints, if any]
Search planning preference: [Standard / Comprehensive; Standard if unspecified]
Databases I require or exclude: [optional; respect these choices]
Access preference: lawful no-key/free access first; no purchases
Private project location: [choose privately; never publish the path]

Follow AGENTS.md, the existing 19-phase registry and Procedures.
Recommend complementary sources for this question; do not require me to
know database names or configure multiple keys on first use.
Use docs/search-modes.md: these are planning conventions, not CLI flags.
Comprehensive does not guarantee complete coverage. Explain only the next necessary
decision and handle technical commands within my authorization.

Prepare a brief Literature Source Plan separating:
- Recommended and available
- Available after free setup
- Requires institutional access
- Manual supplementary search
- Not implemented or not verified

Use actual implementation/configuration evidence. Unknown live access is
not_verified. Explain topic, language, design and coverage tradeoffs.
Honor my explicit source choices/exclusions. Ask once to confirm the source
scope, exact query plan, credential modes and total/per-source HTTP budget
(including probes, retries, pages, record limits and PubMed metadata fetches).
Do not search before this confirmation and applicable scientific approvals.

After approval, execute ordinary technical requests inside that plan without
asking for each one. Continue independently authorized sources when an
optional service fails. Log failed or unexecuted queries honestly, not as
successful zero results. Do not silently switch sources or exceed the budget.

Suggest free-key setup only when useful; explain what still works anonymously.
After I configure/activate a key, perform the already-budgeted verification.
Never expose keys or use my email to register without separate consent.
Institutional access requires genuine entitlement; no subscription bypass.

Draft the Phase 0 Protocol from my question; do not auto-approve it or bypass
screening/evidence Gates. Keep source provenance and coverage gaps visible.
Do not develop personal-library import or treat metadata as full-text evidence.
After authorized discovery, provide the Coverage Report and offer the manual
Google Scholar supplement if useful. Keep unperformed work not_performed and
manual candidates not_imported; do not call reported work completed automatically.
```
