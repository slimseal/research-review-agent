# Standard and Comprehensive search modes

These are **Codex planning conventions**, not implemented CLI presets or a `--mode`
option. Record the user's choice and resulting concrete plan in private planning
artifacts. They share all 19 phases, the same Protocol and scientific Gates.

| | Standard | Comprehensive |
|---|---|---|
| Intent | Practical bounded starting search | Broader planned coverage of relevant dimensions |
| Sources | Usually propose 2–3 complementary supported sources appropriate to the RQ | Assess additional subject, multidisciplinary and manual sources; omit irrelevant providers with reasons |
| Queries | Focused concepts with justified synonyms | Additional terminology, language/design and sensitivity variants where justified |
| Budget | Small explicit page/record/request caps | Larger only if the user confirms; no implicit unlimited execution |
| Manual supplement | Offer Scholar if useful | Assess Scholar/specialist gaps explicitly; still manual, never scraped |
| Completion | Planned tasks completed, failures/gaps visible | Same; never a guarantee of all literature, saturation or systematic-review sufficiency |

Neither mode selects all providers indiscriminately, creates adapters or obtains
institutional rights. Prefer public access where suitable; explain optional keys
only when needed. Honor explicit exclusions over these defaults. Missing optional
access does not block independently authorized sources.

Before any scientific query, Codex proposes exact provider-native strings, filters,
dates, credential modes and HTTP/page/record caps. Include probes, PubMed's two
requests per nonempty page, DOI lookups and any authorized retries. Allocate the
whole-plan total across per-run caps: there is no transactional shared-budget executor.
One confirmation covers the agreed technical scope, not subsequent human scientific reviews.

Afterward inspect the [coverage report](database-access.md): provider-only records
are candidates, not relevant studies. Report omissions, unresolved identities,
language/date/design gaps and failed/unexecuted providers. Request new authorization
before expanding. A budget stop is not proof of scientific completeness.
