# Citation provider assessment

Reviewed 2026-10-17 (Asia/Shanghai), official documentation. Selection: **Crossref backward + OpenAlex forward + lightweight OpenCitations bidirectional**. Reuse the existing stdlib HTTP transport, canonical normalizers, Registry and immutable-response store. No SDKs or global Skills are dependencies.

| Source | Relationship contract | Access, pagination and metadata | Decision |
|---|---|---|---|
| Crossref | A work's deposited `reference` array is outgoing, not a public complete incoming graph. Missing arrays and explicit empty arrays differ. References can be structured, DOI-only or unstructured. | Public DOI metadata requires no key. Polite email and Plus subscription are optional. Single-work reference retrieval is unpaginated. Read current rate/concurrency headers rather than assuming one rate for all endpoint types. | Implement backward and reuse DOI resolution; do not treat `is-referenced-by-count` as a forward edge list. |
| OpenAlex | `referenced_works` is outgoing; `cites:<work-id>` selects incoming works; `related_works` is similarity, not proof of citation. | Work IDs/DOI lookup; result pages with cursor and work metadata. Current anonymous/key budgets and continuation restrictions can block retrieval. | Implement forward with recorded DOI→work-ID lookup and cursor checkpoints; no related recommendations this round. |
| OpenCitations Index v2 | `/references/{id}` outgoing and `/citations/{id}` incoming; `citing`, `cited`, OCI and multiple PIDs identify relations. | Service supports DOI, PMID, OMID and other PIDs; this adapter intentionally accepts DOI seeds only. Optional authorization token, documented 180 requests/minute/IP. Current operations have no documented cursor pagination. Mostly relation/identifier metadata, so new endpoint DOIs use Crossref enrichment. | Implement both directions. Preserve multiple-DOI endpoint ambiguity rather than collapsing preprint/publication versions. |
| Semantic Scholar Graph | Separate `/paper/{id}/references` and `/citations` endpoints, nested cited/citing papers; recommendations are a different API. | Paper/external identifiers, requested metadata fields and offset pagination. Key access/rate policy and licensing add another integration surface. | Evaluated, deferred. Three selected sources already cover required contracts; no key/account requested, no adapter installed. |

Primary evidence for Crossref reference semantics and optional deposits: [References](https://www.crossref.org/documentation/schema-library/markup-guide-metadata-segments/references/). Access and rate headers: [Access and authentication](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/). A later official announcement differentiates request classes, so deployment must honor response headers: [July 2026 limits update](https://community.crossref.org/t/refining-rest-api-limits-for-improved-stability-and-reliability/16137).

OpenAlex relationships and query examples: [API recipes](https://help.openalex.org/how-to/api-recipes/); current budgets and credentials: [Authentication](https://help.openalex.org/api/authentication/). API metadata is not an assertion of scientific validity. Round 2C/2D quota exhaustion remains historical evidence, not a successful live test. This round the OpenAlex run was stopped **locally before HTTP** by the shared candidate cap; no renewed quota diagnosis is claimed.

OpenCitations fields, identifier syntax, optional token, limits and endpoint directions: [Index v2 contract](https://api.opencitations.net/index/v2). API documentation is CC BY 4.0 and RAMOSE software ISC; the organization's data are CC0: [OpenCitations](https://opencitations.net/). A large unpaginated response can exceed the local candidate processing cap: retain raw bytes and expose unprocessed counts; never fabricate pagination.

Semantic Scholar contract: [Graph API documentation](https://api.semanticscholar.org/api-docs/graph); its documentation is JavaScript-rendered and the main product page returned 403 to the documentation browser. Endpoint examples were available in the indexed official documentation, but **no live API call was made**. Review reuse/display and commercial restrictions before future integration: [API license](https://api.semanticscholar.org/license/). Do not assume a public endpoint grants unrestricted downstream redistribution.

## Coverage and maintenance decisions

All graph sources reflect their ingest sources, matching rules and update times. Provider counts are neither completeness guarantees nor quality ratings. Inference for review design: non-DOI books, archives, archaeological catalogs, historical languages and poorly indexed humanities sources require complementary authorized discovery, not an assertion of zero citations. Crossref supports diverse deposited types; this does not establish equal disciplinary coverage. OpenAlex and OpenCitations have broader graph roles but also identifier/matching/version gaps.

Store request URL/parameters, retrieved timestamp, safe headers, body hash, provider record and source-row pointer for every used response. Failures remain explicit; do not switch providers silently or retry exhausted quotas. Raw dataset redistribution requires a separate release review, including third-party text within metadata. This assessment is engineering scope, not legal advice.
